# Final Examination - Full Stack Web Development

One server, one command, port **3000**.

## Run

```bash
npm run serve
```

## Browser

| URL | Response |
|-----|----------|
| http://localhost:3000/ | Welcome to Node.js Server |
| http://localhost:3000/about | About Page |
| http://localhost:3000/contact | Contact Page |
| http://localhost:3000/services | Services Page |

## Postman

| Method | URL |
|--------|-----|
| GET | http://localhost:3000/students |
| POST | http://localhost:3000/students |
| PUT | http://localhost:3000/students |
| DELETE | http://localhost:3000/students |
| POST | http://localhost:3000/add-student |
| GET | http://localhost:3000/students-db |
